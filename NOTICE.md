# External methods and provenance

- TESO: *Online Tracking of Essential Matrix by Stochastic Optimization*,
  official repository commit
  `a309db1f5e5c15ac38e2cf8036f441787be33327`, distributed by its authors under
  CC BY-NC 4.0. This snapshot independently implements only the rotation-only
  Gaussian epipolar-kernel tracker used in the audited fallback experiment.
- LightGlue: commit `eb42fee2d71449efb0aa5c10549752b5d75384d8`,
  Apache-2.0. LightGlue code and weights are not included.
- EfficientLoFTR: commit `ffd4a4644064354468eb1f0c7a3e732233cb732f`,
  used only as a reported baseline in the archived project; not included here.
